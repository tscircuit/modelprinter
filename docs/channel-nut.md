# Spring-Loaded Strut Channel Nut (`channelnut`)

41mm strut-channel nut with dual serrated lip-grip grooves and a bottom positioning coil spring.

## Example Model String

```text
channelnut_m6_w20mm_l35mm_h8mm_grooves2_groovew3mm_groovedepth2mm_springod10mm_springl15mm_springwire1mm
```

## Local Coordinate Datum

- **Origin `(0, 0, 0)`**: Nut block bottom face center (`springBottomZ = -springLength`, `topZ = height`).
