# V-Groove Guide Roller Bearing (`vrollerbearing`)

V625/LV-series track guide wheel bearing with a 90-degree peripheral V-groove.

## Example Model String

```text
vrollerbearing_bore5mm_od24mm_w10mm_angle90deg_groovedepth3mm_vgroove_boremount
```

## Local Coordinate Datum

- **Origin `(0, 0, 0)`**: V-groove vertex plane at bore midpoint (`frontY = -width / 2`, `backY = width / 2`).
