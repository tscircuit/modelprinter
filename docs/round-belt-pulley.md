# O-Ring / Round-Belt Pulley (`roundbeltpulley`)

Cylindrical pulley with a semicircular rim groove and radial set-screw shaft mount.

## Example Model String

```text
roundbeltpulley_od50mm_bore8mm_w12mm_groover3mm_semicirculargroove_setscrew_m4
```

## Local Coordinate Datum

- **Origin `(0, 0, 0)`**: Pulley mid-plane on bore axis (`bottomZ = -width / 2`, `topZ = width / 2`).
