# DIN 71752 Rod-End Clevis Fork (`clevisfork`)

Internally threaded cylindrical shank clevis fork with parallel slotted arms and aligned cross-pin holes.

## Example Model String

```text
clevisfork_threadd6mm_l35mm_gap8mm_armw6mm_armh12mm_arml18mm_pind6mm_holeoffset6mm_shankod10mm_threaddepth12mm
```

## Local Coordinate Datum

- **Origin `(0, 0, 0)`**: Cross-pin bore axis center (`pinX = 0`, `rearShankX = -(length - holeOffset)`).
