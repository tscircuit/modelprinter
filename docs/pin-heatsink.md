# Pin-Fin Array Heatsink (`pinheatsink`)

Square base heatsink with an orthogonal array of cylindrical cooling pins and four corner mounting holes.

## Example Model String

```text
pinheatsink_w30mm_l30mm_base3mm_h20mm_pinod3mm_grid(4,4)_p6mm_holes4_hole3mm_hp(24mm,24mm)
```

## Local Coordinate Datum

- **Origin `(0, 0, 0)`**: Bottom thermal contact face center (`bottomZ = 0`, `topZ = height`).
