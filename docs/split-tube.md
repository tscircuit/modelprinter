# Open-Seam Split Round Tube (`splittube`)

Open-seam cylindrical tube with a continuous longitudinal chord gap through its wall.

## Example Model String

```text
splittube_od25mm_wall2mm_l100mm_gap3mm_chordgap
```

## Local Coordinate Datum

- **Origin `(0, 0, 0)`**: Lower tube end center (`bottomZ = 0`, `topZ = length`).
