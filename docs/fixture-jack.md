# Adjustable Machinist Screw Fixture Jack (`fixturejack`)

Workholding screw jack with a flanged base pedestal, elevating stem, and top contact pad.

## Example Model String

```text
fixturejack_based30mm_baseh10mm_h50mm_travel20mm_stem12mm_m8_threadl10mm_padd20mm_padt5mm
```

## Local Coordinate Datum

- **Origin `(0, 0, 0)`**: Pedestal base bottom center (`baseZ = 0`, `retractedTopZ = height`).
