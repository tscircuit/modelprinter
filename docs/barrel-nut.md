# Cross-Dowel Barrel Nut (`barrelnut`)

Cylindrical cross-dowel nut with a transverse metric thread and slotted alignment end face.

## Example Model String

```text
barrelnut_m6_d10mm_l14mm_holeoffset7mm_slotw1mm_slotdepth2mm_transverse_slotted
```

## Local Coordinate Datum

- **Origin `(0, 0, 0)`**: Plain lower end center (`bottomZ = 0`, slotted face at `topZ = length`).
