# Corrugated Electrical Cable Conduit (`cableconduit`)

Open-ended corrugated electrical conduit sleeve with annular round ribs.

## Example Model String

```text
cableconduit_od20mm_id16mm_l100mm_p4mm_ribdepth1mm_roundcorrugated
```

## Local Coordinate Datum

- **Origin `(0, 0, 0)`**: Lower open conduit end face (`bottomZ = 0`, `topZ = length`).
