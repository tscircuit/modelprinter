# Metal-Bellows Servo Shaft Coupling (`bellowscoupler`)

Torsionally rigid thin-walled stainless bellows coupling with split-clamp aluminum hubs.


## Local Coordinate Datum

- **Origin `(0, 0, 0)`**: Drive-side hub end face center (`startZ = 0`, `endZ = length`).
