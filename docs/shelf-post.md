# Grooved Wire-Shelving Upright Post (`shelfpost`)

Tubular shelving post with periodic annular locating grooves for tapered split shelf sleeves.

## Example Model String

```text
shelfpost_od25mm_wall1.5mm_l600mm_groovepitch25mm_groovew2mm_grooved1mm_firstgroove25mm
```

## Local Coordinate Datum

- **Origin `(0, 0, 0)`**: Lower post end center (`bottomZ = 0`, `topZ = length`).
