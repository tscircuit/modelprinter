# Hex-Head Masonry Expansion Sleeve Anchor (`sleeveanchor`)

Masonry expansion anchor with a four-slotted tubular sleeve and rear cone nut.

## Example Model String

```text
sleeveanchor_m8_l65mm_sleeveod10mm_wall1mm_sleevel45mm_slots4_slotl20mm_coneod10mm_af13mm_hexhead_unset
```

## Local Coordinate Datum

- **Origin `(0, 0, 0)`**: Embedded cone nut base (`bottomZ = 0`, `topZ = length`).
