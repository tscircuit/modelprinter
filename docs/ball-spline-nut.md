# Flanged Ball-Spline Nut Carriage (`ballsplinenut`)

Flanged recirculating ball-spline nut carriage with internal return circuits and four face-mounting holes.

## Example Model String

```text
ballsplinenut_bore20mm_od40mm_l60mm_flangeod60mm_racecount6_face4hole_pcd48mm_holed6mm_internalreturn
```

## Local Coordinate Datum

- **Origin `(0, 0, 0)`**: Flange mounting face center (`bottomZ = 0`, `topZ = length`).
