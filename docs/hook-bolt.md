# Hook Bolt (`hookbolt`)

J-hook bolt bent from round stock with an open 180-degree hook and threaded straight leg (roadmap #13, item 0577).

## Example Model String

```text
hookbolt_custom_m6_straightl50mm_threadl25mm_hookid15mm_hookangle180deg_hookwire6mm_flattip
```

## Local Coordinate Datum

- **Origin `(0, 0, 0)`**: Tangent transition between straight leg and hook bend (`bottomZ = -straightLength`).
