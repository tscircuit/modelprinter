# U-Groove Track Guide Roller Bearing (`grooverollerbearing`)

SG/LFR-series round-rail guide bearing with a semicircular peripheral U-groove.

## Example Model String

```text
grooverollerbearing_bore8mm_od30mm_w12mm_groover4mm_groovedepth4mm_ugroove_boremount
```

## Local Coordinate Datum

- **Origin `(0, 0, 0)`**: U-groove midplane at bore center (`frontY = -width / 2`, `backY = width / 2`).
