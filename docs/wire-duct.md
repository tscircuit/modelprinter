# Slotted-Wall Control-Panel Wiring Duct (`wireduct`)

Open-top rectangular PVC control-panel wiring raceway with equally spaced vertical sidewall finger slots and floor fixing holes.

## Example Model String

```text
wireduct_iw40mm_ih40mm_l150mm_t2mm_slots12_slotw6mm_p10mm_sloth28mm_holes2_hole4mm_hp100mm
```

## Local Coordinate Datum

- **Origin `(0, 0, 0)`**: Exterior bottom mounting face midpoint (`baseZ = 0`, `topEdgeZ = wallThickness + innerHeight`).
