# 3-Way T-Slot Extrusion Corner Cube (`tslotcornercube`)

Solid aluminum extrusion corner connector cube with three mutually perpendicular counterbored bolt bores.

## Example Model String

```text
tslotcornercube_w20mm_h20mm_d20mm_holed5mm_counterbore9mm_counterbored3mm_xyzaxes
```

## Local Coordinate Datum

- **Origin `(0, 0, 0)`**: Intersection of the three orthogonal bore axes at cube centroid.
