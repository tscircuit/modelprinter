# Benchtop Slotted-Jaw PCB Assembly Holder (`pcbholder`)

Bolted benchtop board fixture with opposing V/slot edge jaws suspending a PCB above a 4-hole baseplate.

## Example Model String

```text
pcbholder_span150mm_h80mm_jaww10mm_groovew1.6mm_grooved3mm_basel200mm_basew60mm_mounts4_hole5.5mm_pitchx170mm_pitchy40mm
```

## Local Coordinate Datum

- **Origin `(0, 0, 0)`**: Bottom benchtop mounting plane center (`baseZ = 0`, `jawTopZ = height`).
