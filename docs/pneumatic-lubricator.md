# Modular Air-Line Oil-Mist Lubricator (`pneumaticlubricator`)

Inline pneumatic FRL oil-mist lubricator with lower reservoir bowl, bracket mount holes, and top transparent sight-feed dome.

```text
pneumaticlubricator_npt0.25in_bowlod35mm_h110mm_headw45mm_headd40mm_domeod15mm_domeh15mm_holep30mm_holes2_holed5mm_sightdome
```

## Local Coordinate Datum

- **Origin `(0, 0, 0)`**: Port centerline of manifold head (`portZ = 0`, `domeTopZ = domeHeight`).
