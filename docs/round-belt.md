# Endless Polyurethane Round Drive Belt (`roundbelt`)

Endless circular-cross-section drive belt loop.

## Example Model String

```text
roundbelt_d6mm_l500mm_endless_circular
```

## Local Coordinate Datum

- **Origin `(0, 0, 0)`**: Belt loop mid-plane center (`bottomZ = -crossSectionDiameter / 2`, `topZ = crossSectionDiameter / 2`).
