# Switchable V-Sole Magnetic Indicator Base (`magneticbase`)

Switchable permanent-magnet metrology base block with articulated upright support arm, central locking joint, and indicator stem clamp.

## Example Model String

```text
magneticbase_basel50mm_basew50mm_baseh60mm_arml150mm_armd10mm_jointd20mm_clampbore8mm
```

## Local Coordinate Datum

- **Origin `(0, 0, 0)`**: Bottom magnetic sole plane center (`baseZ = 0`, `deckZ = baseHeight`).
