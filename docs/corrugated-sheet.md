# Sinusoidal Corrugated Cladding Sheet (`corrugatedsheet`)

Wave-stiffened corrugated metal/polycarbonate sheet panel.

## Example Model String

```text
corrugatedsheet_l300mm_w200mm_t1mm_pitch20mm_peaktopeak5mm_phase0deg_sinewave
```

## Local Coordinate Datum

- **Origin `(0, 0, 0)`**: Neutral wave midplane at panel center.
