# Threaded Barrel Inductive Proximity Sensor (`inductivesensor`)

Cylindrical M12-style threaded inductive proximity sensor barrel with flush sensing face, locknuts, and rear pig-tail cable.

## Example Model String

```text
inductivesensor_threadod12mm_threadpitch1mm_l50mm_faceod10mm_cableod5mm_cablel20mm_nuts2_flushfront
```

## Local Coordinate Datum

- **Origin `(0, 0, 0)`**: Front sensing face center (`sensingZ = 0`, `rearCableZ = -(length + cableLength)`).
