# Forged Screw-Pin Chain D-Shackle (`dshackle`)

Forged chain D-shackle with straight parallel legs, semicircular crown arch, lug eyes, and removable threaded cross pin.

## Example Model String

```text
dshackle_innerw25mm_innerh50mm_stock12mm_crownr12.5mm_pin12mm_eyet15mm_pinm12
```

## Local Coordinate Datum

- **Origin `(0, 0, 0)`**: Transverse cross-pin axis midpoint between parallel leg eyes (`pinCenter = (0, 0, 0)`).
