# Fixed Angular-Contact Leadscrew End-Support Block (`leadscrewsupport`)

BK-style pillow-block screw support housing with paired angular-contact bearing bore and 2-bolt base mounting.

## Example Model String

```text
leadscrewsupport_bore12mm_w60mm_h43mm_depth25mm_holepitch46mm_holed5mm_angularpair
```

## Local Coordinate Datum

- **Origin `(0, 0, 0)`**: Base mounting plane below bearing bore axis (`baseZ = 0`, `boreCenterZ = height / 2`).
