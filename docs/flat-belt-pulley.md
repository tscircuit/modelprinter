# Smooth Flat-Rim Belt Pulley (`flatbeltpulley`)

Smooth cylindrical flat-belt drive pulley with a keyed shaft bore.

## Example Model String

```text
flatbeltpulley_od80mm_bore12mm_w30mm_flatrim_keyway_keyw4mm
```

## Local Coordinate Datum

- **Origin `(0, 0, 0)`**: Pulley mid-plane on bore axis (`bottomZ = -width / 2`, `topZ = width / 2`).
