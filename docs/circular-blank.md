# Solid Circular Machining Blank (`circularblank`)

Solid round disc stock blank with flat faces and optional rim edge rounding.

## Example Model String

```text
circularblank_d80mm_t10mm_rimr0mm
```

## Local Coordinate Datum

- **Origin `(0, 0, 0)`**: Disc centroid (`bottomZ = -thickness / 2`, `topZ = thickness / 2`).
