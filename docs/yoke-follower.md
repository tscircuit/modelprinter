# Yoke-Type Needle Cam Follower (`yokefollower`)

RNA22/NATV bore-mounted needle cam follower with a heavy outer running ring.

## Example Model String

```text
yokefollower_bore10mm_od30mm_w14mm_rows1_needle_open_boremount
```

## Local Coordinate Datum

- **Origin `(0, 0, 0)`**: Inner-sleeve bore midpoint (`frontY = -width / 2`, `backY = width / 2`).
