# Multi-Bore Panel Cable Grommet (`multigrommet`)

Round panel-groove elastomeric grommet with multiple cable pass-through bores arranged on a pitch circle.

## Example Model String

```text
multigrommet_od30mm_h10mm_panelhole25mm_groovew3mm_bores4_id4mm_borepcd12mm
```

## Local Coordinate Datum

- **Origin `(0, 0, 0)`**: Panel groove mid-plane center (`bottomZ = -height / 2`, `topZ = height / 2`).
