# Cylindrical Cartridge Bearing Unit (`cartridgebearing`)

Cylindrical bearing cartridge housing with a stepped locating end flange for press/slip insertion into a machine frame bore.

## Example Model String

```text
cartridgebearing_bore25mm_od62mm_l45mm_cylindricalfit_locatingflangeod75mm_flangeh5mm
```

## Local Coordinate Datum

- **Origin `(0, 0, 0)`**: Rear pilot cylinder face (`bottomZ = 0`, `topZ = length`).
