# Welded Bar-Grid Walkway Grating (`gridgrating`)

Open industrial steel walkway grating panel formed from deep bearing bars and flush top crossbars.

## Example Model String

```text
gridgrating_l300mm_w200mm_h25mm_bart3mm_pitch25mm_crosst3mm_crossh5mm_crosspitch50mm
```

## Local Coordinate Datum

- **Origin `(0, 0, 0)`**: Bottom support plane center (`bottomZ = 0`, `topZ = bearingBarHeight`).
