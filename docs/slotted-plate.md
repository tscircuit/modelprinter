# Perforated Slotted Sheet Plate (`slottedplate`)

Flat stock sheet panel perforated with a rectangular array of elongated stadium slots.

## Example Model String

```text
slottedplate_l200mm_w100mm_t2mm_slotl10mm_slotw3mm_pitchx15mm_pitchy10mm_edgex10mm_edgey10mm
```

## Local Coordinate Datum

- **Origin `(0, 0, 0)`**: Plate midplane centroid (`bottomZ = -thickness / 2`, `topZ = thickness / 2`).
