# Perforated Slotted Screen Tube (`slottedtube`)

Round hollow tube with regular rows of circumferential wall slots.

## Example Model String

```text
slottedtube_od25mm_wall2mm_l100mm_slotw3mm_slotl8mm_axialpitch10mm_rows9_around8_end10mm
```

## Local Coordinate Datum

- **Origin `(0, 0, 0)`**: Lower tube end face center (`bottomZ = 0`, `topZ = length`).
