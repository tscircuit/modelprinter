# Graduated Machine-Vise Swivel Base (`viseswivelbase`)

Rotary machine-vise turntable base with central pilot register and dual arcuate T-bolt slots.

## Example Model String

```text
viseswivelbase_od200mm_h35mm_baset15mm_topod160mm_topt20mm_pilot80mm_piloth5mm_arcs2_arcpcd170mm_arcangle60deg_arcw12mm_topholes4_tophole10.5mm_pitchx100mm_pitchy60mm
```

## Local Coordinate Datum

- **Origin `(0, 0, 0)`**: Table seating plane center (`bottomZ = 0`, `topZ = height`).
