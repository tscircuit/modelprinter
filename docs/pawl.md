# Ratchet Locking Pawl (`pawl`)

Pivoting ratchet locking pawl with cylindrical pivot bore and tapered tooth-engaging nose.

## Example Model String

```text
pawl_l35mm_w12mm_h8mm_pivotd6mm_pivotbore_noseangle20deg_noseradius2mm
```

## Local Coordinate Datum

- **Origin `(0, 0, 0)`**: Lower face at pivot bore axis (`bottomZ = 0`, `topZ = height`).
