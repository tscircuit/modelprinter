# T-Slot Extrusion Tee Joining Plate (`tslotteeplate`)

Flat T-shaped joining plate for 20/30-series aluminum T-slot extrusions.

## Example Model String

```text
tslotteeplate_w80mm_h60mm_armw20mm_t4mm_holes5_hole5mm_p20mm_tee
```

## Local Coordinate Datum

- **Origin `(0, 0, 0)`**: Intersection of crossbar and stem centerlines on bottom face (`bottomZ = 0`, `topZ = thickness`).
