# Holonomic Tangential-Roller Omni Wheel (`omniwheel`)

Holonomic robotics wheel with tangentially oriented peripheral barrel rollers and keyed drive hub.

## Example Model String

```text
omniwheel_od60mm_w25mm_bore8mm_rollers8_keyway_keyw3mm_tangentialrollers
```

## Local Coordinate Datum

- **Origin `(0, 0, 0)`**: Wheel mid-plane on hub bore axis (`bottomZ = -width / 2`, `topZ = width / 2`).
