# Knurled Round Thumb Nut (`thumbnut`)

Tool-free cylindrical thumb nut with peripheral knurling and chamfered faces.

## Example Model String

```text
thumbnut_m4_od12mm_h6mm_knurlp1mm_chamfer0.5mm_through_straightknurl
```

## Local Coordinate Datum

- **Origin `(0, 0, 0)`**: Lower bearing face center (`bottomZ = 0`, `topZ = height`).
