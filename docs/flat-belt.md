# Endless Smooth Flat Drive Belt (`flatbelt`)

Endless smooth flat transmission belt with rectangular cross section.

## Example Model String

```text
flatbelt_l600mm_w25mm_h2mm_endless_rectangular
```

## Local Coordinate Datum

- **Origin `(0, 0, 0)`**: Belt loop mid-plane center (`bottomZ = -width / 2`, `topZ = width / 2`).
