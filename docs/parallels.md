# Matched Machinist Vise Parallels (`parallels`)

Matched pair of ground rectangular steel bars supporting workpieces above a machine vise bed.

## Example Model String

```text
parallels_l100mm_h20mm_t5mm_pairgap50mm_edger0mm
```

## Local Coordinate Datum

- **Origin `(0, 0, 0)`**: Midpoint between matched bars on vise bed (`bedZ = 0`, `supportTopZ = height`).
