# Machined-Ring Needle Roller Bearing (`needlerollerbearing`)

NA/NK machined-ring radial needle bearing with optional separate inner sleeve.

## Example Model String

```text
needlerollerbearing_id20mm_od28mm_w20mm_rows1_innerring1_open
```

## Local Coordinate Datum

- **Origin `(0, 0, 0)`**: Bore axis midpoint (`frontY = -width / 2`, `backY = width / 2`).
