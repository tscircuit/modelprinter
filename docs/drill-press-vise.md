# Compact Open-Base Drill-Press Machine Vise (`drillpressvise`)

Low-profile drill-press vise with opposed fixed and sliding jaws, open through-drilling bed, and 4 slotted table mounting lugs.

## Example Model String

```text
drillpressvise_jaww75mm_jawh25mm_open80mm_bodyl180mm_bodyw90mm_h45mm_mountslots4_slotw8mm_slotl20mm_pitchx140mm_pitchy75mm
```

## Local Coordinate Datum

- **Origin `(0, 0, 0)`**: Bottom table mounting plane center (`baseZ = 0`, `topJawZ = height`).
