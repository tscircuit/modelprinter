# DIN Terminal Block End Plate (`terminalendplate`)

Flat insulating end partition plate with stepped terminal outline, TH35x7.5 rail notch, and locating pins.

## Example Model String

```text
terminalendplate_w30mm_h40mm_t2mm_steppedterminal_th35x7.5_pins2_pinod2mm_pinp20mm
```

## Local Coordinate Datum

- **Origin `(0, 0, 0)`**: Base DIN-rail seating edge center (`bottomZ = 0`, `topZ = height`).
