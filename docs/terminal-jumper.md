# Comb Terminal Bridge Jumper (`terminaljumper`)

Multi-pole conductive comb bridge with a straight top spine and downward insertion prongs.

## Example Model String

```text
terminaljumper_p5mm_n4_t1mm_stripw4mm_prongw2mm_prongl8mm_comb
```

## Local Coordinate Datum

- **Origin `(0, 0, 0)`**: Lower edge of the top bridge spine (`bottomZ = -prongLength`, `topZ = stripWidth`).
