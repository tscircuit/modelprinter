# Concrete Expansion Wedge Stud Anchor (`wedgeanchor`)

Through-bolt concrete stud anchor with rear tapered cone and split expansion clip.

```text
wedgeanchor_m8_l75mm_threadl30mm_clipod10mm_clipl12mm_coneod10mm_conel10mm_headless_unset
```

## Local Coordinate Datum

- **Origin `(0, 0, 0)`**: Embedded expansion-cone base (`coneEndZ = 0`, `studTipZ = length`).
