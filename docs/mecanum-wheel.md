# Omnidirectional 45-Degree Mecanum Wheel (`mecanumwheel`)

Omnidirectional robotics wheel with angled peripheral rollers and keyed drive hub.

## Example Model String

```text
mecanumwheel_od100mm_w50mm_bore10mm_rollers8_angle45deg_keyway_keyw3mm_righthand
```

## Local Coordinate Datum

- **Origin `(0, 0, 0)`**: Wheel mid-plane on hub bore axis (`bottomZ = -width / 2`, `topZ = width / 2`).
