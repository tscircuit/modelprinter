# Split Plumber-Block Bearing Housing (`splitpillowblock`)

SNL/SNH split cast-iron pedestal housing with removable bolted cap and dual slotted base feet.

## Example Model String

```text
splitpillowblock_bore40mm_l180mm_w60mm_h110mm_slotpitch150mm_slotw14mm_slotl20mm_base2slot
```

## Local Coordinate Datum

- **Origin `(0, 0, 0)`**: Pedestal base mounting plane center (`baseZ = 0`, `topZ = height`).
