# Solid Threaded Repair Insert (`solidinsert`)

Solid thick-wall thread repair bushing with internal metric thread, external metric thread, and top screwdriver installation slot.

## Example Model String

```text
solidinsert_custom_m6_externald10mm_externalthreadpitch1.5mm_l12mm_slotted_slotw1mm_slotdepth1.5mm_through
```

## Local Coordinate Datum

- **Origin `(0, 0, 0)`**: Slotted flush top face (`bottomZ = -length`, `topZ = 0`).
