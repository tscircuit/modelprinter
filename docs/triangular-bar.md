# Solid Equilateral Triangular Bar (`triangularbar`)

Solid equilateral triangular stock bar with three longitudinal flat faces.

## Example Model String

```text
triangularbar_side20mm_l100mm_equilateral_cornerr0mm
```

## Local Coordinate Datum

- **Origin `(0, 0, 0)`**: Lower bar end centroid (`bottomZ = 0`, `topZ = length`).
