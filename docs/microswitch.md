# Subminiature Lever Snap Microswitch (`microswitch`)

Miniature snap-action switch with a straight top hinge lever, two side mounting holes, and three solder lug contacts.

## Example Model String

```text
microswitch_w20mm_h10mm_d6mm_leverl25mm_t0.5mm_holes2_hole2mm_hp9.5mm_contacts3_solderlug
```

## Local Coordinate Datum

- **Origin `(0, 0, 0)`**: Lower switch body base center (`bottomZ = 0`, `topZ = height`).
