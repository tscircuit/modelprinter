# Castellated Hex Locknut (`castellatednut`)

Hexagonal nut topped with a slotted cylindrical turret for cotter-pin retention.

## Example Model String

```text
castellatednut_m6_af10mm_h8mm_castleod9mm_castleh3mm_slots6_slotw1.5mm_slotdepth3mm
```

## Local Coordinate Datum

- **Origin `(0, 0, 0)`**: Bearing face center (`bottomZ = 0`, `topZ = height`).
