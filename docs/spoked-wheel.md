# Cast Spoked Drive Wheel (`spokedwheel`)

Spoked wheel joining a keyed central drive hub to an outer tread rim.

## Example Model String

```text
spokedwheel_od150mm_w25mm_bore15mm_spokes6_keyway_keyw5mm_hubw30mm
```

## Local Coordinate Datum

- **Origin `(0, 0, 0)`**: Wheel mid-plane on hub bore axis (`bottomZ = -overallWidth / 2`, `topZ = overallWidth / 2`).
