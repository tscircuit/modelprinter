# Forged Screw-Pin Anchor Bow Shackle (`bowshackle`)

Forged omega-bow rigging shackle with enlarged curved loop, thickened lug eyes, and removable threaded cross pin.

## Example Model String

```text
bowshackle_innerw40mm_innerh60mm_stock12mm_bowr30mm_pin12mm_eyet15mm_pinm12
```

## Local Coordinate Datum

- **Origin `(0, 0, 0)`**: Transverse pin axis midpoint between lug eyes (`pinCenter = (0, 0, 0)`).
