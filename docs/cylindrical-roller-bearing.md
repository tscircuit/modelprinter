# Cylindrical Roller Bearing (`cylindricalrollerbearing`)

Single- or double-row cylindrical roller bearing with NU/NJ/NUP ring flange layout.

## Example Model String

```text
cylindricalrollerbearing_id25mm_od52mm_w15mm_rows1_nu_open
```

## Local Coordinate Datum

- **Origin `(0, 0, 0)`**: Bearing bore midpoint (`frontY = -width / 2`, `backY = width / 2`).
