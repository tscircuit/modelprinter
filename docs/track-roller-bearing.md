LR/NATR heavy-outer-ring crowned track roller with a through mounting bore.

```text
trackrollerbearing_bore15mm_od40mm_w18mm_rows2_crownradius500mm_shielded_boremount
```

## Local Coordinate Datum

- **Origin `(0, 0, 0)`**: Bore axis midpoint (`frontY = -width / 2`, `backY = width / 2`).
