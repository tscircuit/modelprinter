# Cylindrical Cartridge Fuse (`cartridgefuse`)

Ceramic cylindrical cartridge fuse envelope with metallic end caps.

## Example Model String

```text
cartridgefuse_cartridge5x20_od5mm_l20mm_capl5mm_ceramiccylinder
```

## Local Coordinate Datum

- **Origin `(0, 0, 0)`**: Midpoint of the cylindrical fuse axis (`bottomZ = -length / 2`, `topZ = length / 2`).
