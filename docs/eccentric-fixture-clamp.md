# Low-Profile Eccentric Cam Fixture Clamp (`eccentricfixtureclamp`)

Serrated cylindrical eccentric workholding cam washer with off-center screw bore and hex wrench socket.

## Example Model String

```text
eccentricfixtureclamp_od30mm_h10mm_bore6.6mm_offset3mm_toothdepth1mm_toothpitch3mm_tophex5mm
```

## Local Coordinate Datum

- **Origin `(0, 0, 0)`**: Bottom cam base plane at off-center fixing bore axis (`bottomZ = 0`, `topZ = height`).
