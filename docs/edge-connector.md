# Dual-Row Card-Edge Connector (`edgeconnector`)

Through-hole dual-row PCB card-edge receptacle with a centered top-entry card slot.

## Example Model String

```text
edgeconnector_p2.54mm_contacts20_rows2_board1.6mm_l35mm_h12mm_d8mm_throughhole_topslot
```

## Local Coordinate Datum

- **Origin `(0, 0, 0)`**: Host PCB mounting face center (`bottomZ = 0`, `topZ = height`).
