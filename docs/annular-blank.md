# Ring-Shaped Annular Machining Blank (`annularblank`)

Hollow annular disc stock blank with flat faces and an open central bore.

## Example Model String

```text
annularblank_od80mm_id40mm_t10mm_rimr0mm
```

## Local Coordinate Datum

- **Origin `(0, 0, 0)`**: Ring centroid (`bottomZ = -thickness / 2`, `topZ = thickness / 2`).
