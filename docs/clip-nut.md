# U-Folded Panel-Edge Clip Nut (`clipnut`)

Spring-steel U-clip nut with an extruded threaded barrel on one leg for sheet-edge fastening.

## Example Model String

```text
clipnut_m4_w12mm_l18mm_gap2mm_strip0.8mm_holeoffset12mm_barrelod6mm_barrelh3mm_uform
```

## Local Coordinate Datum

- **Origin `(0, 0, 0)`**: Thread bore axis at sheet-gap midplane (`panelMidZ = 0`).
