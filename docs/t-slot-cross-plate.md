# T-Slot Extrusion Cross Joining Plate (`tslotcrossplate`)

Symmetric four-arm cruciform joining plate for orthogonal T-slot frame intersections.

## Example Model String

```text
tslotcrossplate_w80mm_h80mm_armw20mm_t4mm_holes5_hole5mm_p30mm_cross
```

## Local Coordinate Datum

- **Origin `(0, 0, 0)`**: Center bolt hole on bottom face (`bottomZ = 0`, `topZ = thickness`).
