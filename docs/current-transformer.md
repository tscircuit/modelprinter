# Closed-Core Window Current Transformer (`currenttransformer`)

Closed-core current sensor housing with circular primary conductor aperture, top secondary terminals, and side mounting tabs.

## Example Model String

```text
currenttransformer_w40mm_h45mm_d20mm_bore20mm_terminals2_tabs2_hole4mm_hp50mm_closedring
```

## Local Coordinate Datum

- **Origin `(0, 0, 0)`**: Base mounting plane center (`bottomZ = 0`, `topZ = height`).
