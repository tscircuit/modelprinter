# Two-Stage Stepped Compound Spur Gear (`compoundgear`)

Monolithic coaxial two-stage spur gear cluster with distinct pinion and wheel tooth counts and a keyed shaft bore.

## Example Model String

```text
compoundgear_teetha16_teethb40_module1mm_w16mm_bore8mm_pa20deg_keyway_keyw3mm
```

## Local Coordinate Datum

- **Origin `(0, 0, 0)`**: Lower stage face on bore centerline (`bottomZ = 0`, `topZ = width`).
