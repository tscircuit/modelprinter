# Drawn-Cup Needle Roller Bearing (`drawncupbearing`)

HK/BK thin-shell stamped outer-cup needle bearing running directly on a hardened shaft.

## Example Model String

```text
drawncupbearing_id10mm_od14mm_w12mm_rows1_innerring0_openended
```

## Local Coordinate Datum

- **Origin `(0, 0, 0)`**: Bore axis midpoint (`frontY = -width / 2`, `backY = width / 2`).
