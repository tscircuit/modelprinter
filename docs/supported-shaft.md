# SBR-Style Continuously Supported Linear Guide Shaft (`supportedshaft`)

Hardened round linear guideway shaft mounted atop an extruded aluminum base rail with pre-drilled flange holes.

## Example Model String

```text
supportedshaft_d16mm_l300mm_basew40mm_baseh20mm_holepitch50mm_holed6mm_shaftcenterh28mm_baseholes
```

## Local Coordinate Datum

- **Origin `(0, 0, 0)`**: Support rail bottom mounting plane (`baseZ = 0`, `shaftCenterZ = shaftCenterHeight`).
