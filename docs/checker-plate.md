# Raised Diamond Tread Checker Plate (`checkerplate`)

Anti-slip floor plate with an orthogonal grid of 45-degree raised traction lugs.

## Example Model String

```text
checkerplate_l200mm_w100mm_t3mm_rise1mm_treadl12mm_treadw3mm_pitchx20mm_pitchy20mm_angle45deg
```

## Local Coordinate Datum

- **Origin `(0, 0, 0)`**: Smooth underside center (`bottomZ = 0`, `treadPeakZ = thickness + rise`).
