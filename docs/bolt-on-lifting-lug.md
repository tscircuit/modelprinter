# Gusseted 4-Bolt Lifting Padeye Lug (`boltonliftinglug`)

Welded/cast upright lifting padeye with side stiffener gussets on a 4-bolt base flange.

## Example Model String

```text
boltonliftinglug_basew100mm_based80mm_baset12mm_h90mm_lugw60mm_lugt15mm_eye25mm_eyez60mm_topr30mm_mounts4_hole11mm_pitchx80mm_pitchy60mm_gussets2_gussett8mm_gusseth45mm
```

## Local Coordinate Datum

- **Origin `(0, 0, 0)`**: Base flange mounting plane center (`baseZ = 0`, `topZ = eyeZ + topRadius`).
