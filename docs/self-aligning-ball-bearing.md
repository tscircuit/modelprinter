# Self-Aligning Double-Row Ball Bearing (`selfaligningballbearing`)

1200/2200-series double-row ball bearing with a common spherical outer raceway.

## Example Model String

```text
selfaligningballbearing_id20mm_od47mm_w14mm_rows2_open_sphericalouter
```

## Local Coordinate Datum

- **Origin `(0, 0, 0)`**: Spherical raceway center at bore midpoint.
