# Radial-Fin Star LED Heatsink (`ledheatsink`)

Circular radial-fin emitter heatsink with a flat central mounting boss and two emitter screw holes.

## Example Model String

```text
ledheatsink_od50mm_h20mm_base3mm_seatod20mm_fins16_fint1mm_holes2_hole3mm_hp16mm
```

## Local Coordinate Datum

- **Origin `(0, 0, 0)`**: Emitter contact face center (`bottomZ = 0`, `topZ = height`).
