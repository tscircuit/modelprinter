# Coaxial Cylindrical Planetary Gearmotor (`planetarygearmotor`)

Cylindrical DC motor coupled to an inline planetary reduction gearbox with four front tapped holes.

## Example Model String

```text
planetarygearmotor_motorod50mm_l140mm_shaftd12mm_face4hole_pcd40mm_m4_coaxial
```

## Local Coordinate Datum

- **Origin `(0, 0, 0)`**: Front gearbox mounting face center (`bottomZ = -length`, `topZ = 0`).
