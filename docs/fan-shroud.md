# Square-to-Round Fan Transition Shroud (`fanshroud`)

Hollow tapered square-to-round airflow transition shroud with a four-hole square inlet flange.

## Example Model String

```text
fanshroud_w60mm_h60mm_d20mm_exitod40mm_wall2mm_hole4mm_hp(50mm,50mm)_squaretoround
```

## Local Coordinate Datum

- **Origin `(0, 0, 0)`**: Square inlet flange mounting plane (`bottomZ = 0`, `topZ = depth`).
