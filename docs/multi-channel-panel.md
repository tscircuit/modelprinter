# Twin-Wall Multi-Channel Sheet Panel (`multichannelpanel`)

Hollow twin-wall panel with flat outer skins separated by parallel longitudinal partition ribs.

## Example Model String

```text
multichannelpanel_l200mm_w100mm_t8mm_skint1mm_webt1mm_pitch10mm_channels10
```

## Local Coordinate Datum

- **Origin `(0, 0, 0)`**: Lower skin face center (`bottomZ = 0`, `topZ = thickness`).
