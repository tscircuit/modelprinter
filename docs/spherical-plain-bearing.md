# Radial Spherical Plain Bearing (`sphericalplainbearing`)

GE20E-style radial spherical plain bearing with a convex inner ball and matching outer raceway.

## Example Model String

```text
sphericalplainbearing_id20mm_od35mm_w16mm_misalignment8deg_radial_open
```

## Local Coordinate Datum

- **Origin `(0, 0, 0)`**: Spherical articulation center (`frontY = -width / 2`, `backY = width / 2`).
