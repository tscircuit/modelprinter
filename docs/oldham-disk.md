# Floating Oldham Coupling Torque Disk (`oldhamdisk`)

Floating central Oldham coupling slider disk with orthogonal raised drive tongues on opposing faces.

## Example Model String

```text
oldhamdisk_od30mm_w10mm_tonguew8mm_tongueh3mm_orthogonaltongues_floating
```

## Local Coordinate Datum

- **Origin `(0, 0, 0)`**: Disk mid-plane center (`bottomZ = -width / 2`, `topZ = width / 2`).
