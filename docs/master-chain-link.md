# Spring-Clip Roller-Chain Master Connecting Link (`masterchainlink`)

Roller-chain connecting link with twin pins, removable side plate, and slotted spring retaining clip.

## Example Model String

```text
masterchainlink_pitch12.7mm_w16mm_pind3.96mm_springclip_innerw7.85mm
```

## Local Coordinate Datum

- **Origin `(0, 0, 0)`**: Midpoint between pin axes at link mid-width (`bottomZ = -width / 2`, `topZ = width / 2`).
