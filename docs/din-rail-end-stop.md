# Screw-Clamp DIN Rail End Stop (`dinrailendstop`)

Screw-clamping TH35x7.5 DIN-rail end bracket that prevents lateral sliding of terminal blocks.

## Example Model String

```text
dinrailendstop_th35x7.5_w10mm_d35mm_h30mm_m4_jawgap35mm_screwclamp
```

## Local Coordinate Datum

- **Origin `(0, 0, 0)`**: DIN-rail seating plane center (`bottomZ = 0`, `topZ = height`).
