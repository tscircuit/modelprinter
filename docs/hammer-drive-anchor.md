# Mushroom-Head Hammer-Drive Pin Anchor (`hammerdriveanchor`)

Slotted masonry pin anchor with an integral mushroom flange and projecting center nail pin.

## Example Model String

```text
hammerdriveanchor_d6mm_l40mm_headod12mm_headh2mm_pind2mm_pinexposed5mm_slots2_slotl15mm_unset
```

## Local Coordinate Datum

- **Origin `(0, 0, 0)`**: Anchor nose tip (`tipZ = 0`, `pinTopZ = length + pinExposed`).
