# Telescopic Tube Valco-Style Snap Button (`snapbutton`)

V-folded leaf-spring telescopic tube locking clip with a round push button.

## Example Model String

```text
snapbutton_buttond8mm_buttonh4mm_springw8mm_springth0.5mm_legl25mm_angle40deg_tubeid20mm
```

## Local Coordinate Datum

- **Origin `(0, 0, 0)`**: Button base on active spring leg (`buttonTipZ = buttonHeight`).
