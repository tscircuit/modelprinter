# Intermittent-Motion Geneva Wheel (`genevawheel`)

Slotted Geneva indexing wheel with radial drive-pin slots, concave dwell-locking arcs, and keyed central shaft bore.

## Example Model String

```text
genevawheel_od60mm_w10mm_bore8mm_slots6_keyway_keyw3mm_slotw6mm_lockradius20mm
```

## Local Coordinate Datum

- **Origin `(0, 0, 0)`**: Wheel mid-plane on bore axis (`bottomZ = -width / 2`, `topZ = width / 2`).
