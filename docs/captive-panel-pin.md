# Spring-Loaded Captive Panel Indexing Pin (`captivepanelpin`)

Pull-knob captive indexing pin with integral stop collar and exposed return spring.

## Example Model String

```text
captivepanelpin_d6mm_l25mm_knobod15mm_knobh8mm_collarod10mm_collarh2mm_springod8mm_wire0.8mm_stroke5mm_extended
```

## Local Coordinate Datum

- **Origin `(0, 0, 0)`**: Knob underside datum (`tipZ = -length`, `knobTopZ = knobHeight`).
