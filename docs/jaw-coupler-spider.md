# Curved-Jaw Coupling Elastomer Spider (`jawcouplerspider`)

ROTEX/plum-style polyurethane elastomer spider insert for zero-backlash curved-jaw shaft couplings.

## Example Model String

```text
jawcouplerspider_od30mm_id10mm_w10mm_lobes6_hubclearance10mm_curvedlobe
```

## Local Coordinate Datum

- **Origin `(0, 0, 0)`**: Spider center (`frontY = -width / 2`, `backY = width / 2`).
