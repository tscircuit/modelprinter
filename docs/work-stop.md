# Adjustable Fixture Positioning Work Stop (`workstop`)

Bolted machine-table positioning work stop with 2-hole slotted base block, adjustable extension arm, and hardened contact tip.

## Example Model String

```text
workstop_basel60mm_basew30mm_baset10mm_arm80mm_armd12mm_tip6mm_tiplen20mm_mountholes2_hole6.6mm_pitch40mm
```

## Local Coordinate Datum

- **Origin `(0, 0, 0)`**: Bottom baseplate mounting face center (`baseZ = 0`, `baseTopZ = baseThickness`).
